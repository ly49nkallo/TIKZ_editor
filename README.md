# TIKZ_editor

This repository was created to help make TIKZ figures for LaTeX documents in order to expedite the creation of problems for the Berkeley Physics Tournament.

The script requires no external dependencies (unless somehow you managed to install python without Tkinter). To run, just execute
```python3
python3 fully_compiled.py
```
or, alternatively (for the most recent development version)
```python3
python3 TIKZ_GUI_Editor_tool.py
```
which imports the other two files.
